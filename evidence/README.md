公开仓库只保留这份治理说明，不公开开发机生成的原始 evidence。原始 receipt、
acceptance、生命周期事件和测试输出可能包含绝对路径、进程与窗口标识、显示器信息、
本地设置或其他机器事实，应留在私有证据域并采用追加式、不可覆盖治理。

公开 Release 只能附带专门生成的脱敏摘要。摘要必须绑定公开 commit 和实际 artifact
哈希，区分探索结果、正式验收结果与最终引用结果，并写明没有完成的环境门禁。测试
数量、schema 和 hash 是完整性工具，不能单独证明产品可发布、内容获授权或第三方
许可已经履行。

公开快照导出器允许本文件进入仓库，同时强制排除 `evidence/` 下的其他文件。发现
漂移时先判断是实现、工具、文档还是原始事实变化；不得为了通过检查修改旧证据或
把本机日志复制到公开 Issue、PR 和 Release。
