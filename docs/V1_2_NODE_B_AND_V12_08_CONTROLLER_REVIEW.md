## D08-01（P1）：真实成功路径缺少身份场景，也未校验窗口归属

`verify_displays.py::run_harness` 仅在窗口缺失时写 identity_binding INVALID，
成功获得 live hwnd 时没有对应的 PASS 分支。因此一个正常运行的 harness
必然缺少必需身份场景，validate_display_report 会拒绝报告。主控以合成
Target/时钟/窗口观测执行真实 run_harness，独立复现该缺项与 baseline INVALID。
main 又只检查实际存在的场景值，不检查聚合结果/必需项，因此可能退出 0。

同时代码没有比较自报 pid 与启动进程、没有核验 HWND 的归属进程，报告仅写
启动 pid 字符串，exe_sha256 取自启动前的 Target。不能据此宣称已经绑定实际
观察到的窗口。复验输入故意给启动 pid=123、自报 pid=999，差异未被检查。

要求：补完整成功/失败路径及可审计的身份关联证据；检查候选、启动进程、自报
身份和原生窗口之间的关系，确需支持宿主/代理时明确可验证关联，不能跳过归属
检查。成功正常窗、外来窗、缺窗、退出进程各有编排测试；完整报告契约和退出码
一致。启动后任何异常都应经 finally 清理本次拥有的进程，而非只在正常尾部清理。

## D08-02（P1）：报告校验信任结果标签，INVALID 还被降成 SKIP

`aggregate_display_verdicts` 对 baseline 三项中的 INVALID 没有传播分支。
分别令 identity_binding、display_facts、window_containment 为 INVALID，
其余 PASS，主控实际得到两个总裁决均 SKIP。这把观测失效写成环境未覆盖。

`validate_display_report` 只验证结果枚举和非空 detail；不要求显示器、窗口
矩形、脚底样本、前后拓扑、进程归属等实际观测。独立构造无 displays、无
HWND/窗口样本、无拓扑事件，仅将所有场景标 PASS、三个拓扑布尔值设 True 的
报告，校验返回 []；candidate.kind='source' 且填入匹配 receipt 的 sha256，
`_displays_outcomes` 返回 PASS/PASS。重算相同标签并不是重算观测结论。

要求：定义每场景必需的结构化证据及类型/范围/一致性检查，基于观测重算结论；
拓扑属性由真实显示器记录推导、恢复必须有前后事件、EXE 消费强制候选类型与
身份匹配。缺观测或畸形输入为 INVALID，环境确实不足才 SKIP。测试无观测全
PASS、伪拓扑、错误类型、INVALID 传播与正确报告对照。

## D08-04（P2）：拓扑变化基准被覆盖，缺逐屏行为证据

观察循环发现 fingerprint 变化后，立即把 topology 更新为新值并 break；
最终又比较“更新后的 topology”和当前枚举。一次正常变化并稳定后两者相同，
反而记“no topology change”。独立编排测试在观察期 0.4 秒处改变拓扑，最终
得到 SKIP，复现了已发生事件被丢弃。

另外脚本仅在初始落点观察窗口，没有让它逐屏落点/跨 DPI 并记录结果；最终
可能只因一次无关屏幕变化、窗口仍在原屏就宣称多屏认证。当前 topology
fingerprint 也未包含 work area，工作区变化未被纳入记录。

要求：保留不可覆盖的 before/event/after 记录，稳定期复验与真实事件关联；
不能靠正好在后续面板阶段再发生第二次变化才 PASS。将必需逐屏/DPI 场景与
实际覆盖记录对应，未访问的目标不算通过，环境不足准确 SKIP。

## D08-05（P2）：显示事实仍缺失败检测与完整边界校验

要求：明确 DPI awareness 与坐标单位，检查 Win32 调用返回值、句柄参数与
完整矩形/数值范围；系统 DPI 回退可以作为事实展示，但不能冒充逐屏实测。
补返回失败、零 DPI、工作区右/下越界的负向测试。本轮对此为代码审阅结论，
不宣称已在真实混合 DPI 机器完成验证。

### 2. mapToGlobal 返回值不能直接声明为物理屏幕像素（P2）

逻辑坐标体系。本轮受控 offscreen 探针设置 QT_SCALE_FACTOR=2：DPR=2，

8 物理像素门槛可靠裁决。

收口条件：明确并统一坐标与容差单位，保存足够的 DPI/映射证据供独立推导；
若采用物理像素，应正确处理屏幕原点及跨屏映射，不能将整个 Qt 全局坐标
简单乘 DPR。至少补 1 倍/2 倍下等价物理位移的正反例，并修正文档中的单位
说明。该探针仅证明 Qt 单位差异，不等于完成混合 DPI 真机认证。
