本工单把本地 Todo 中仍开放的“工作联动、动画优化、逻辑优化、细节优化”和
1.2.0 尚未完成的公开发布工作合并为一个版本。目标版本为 **1.3.0**。1.2.0
保留为已取得 `ALPHA-GO`、但没有公开发布的内部基线；不再补发 1.2.0 二进制，
也不覆盖它的 receipt、acceptance 或其他证据。1.3.0 完成后从新提交重新构建、
重新验收，再统一进入公开快照和发布流程。

这是给执行者的完整需求与验收口径，不是完成证明。执行者可以自行设计类、文件、
测试组织和内部接口，可以修复实施中发现的关联缺陷，不需要为普通工程选择逐项请示。
遇到会改变用户数据含义、突破隐私边界、改变公开授权或删改冻结证据的事项，写出
方案和影响交主控裁定，其余工作继续推进。

## 3. 冻结的产品决定

以下决定作为本单默认口径，执行者无需再问：

1. **版本使用 1.3.0。** 开发期先保留现有版本字符串，集成候选前一次性收敛所有
   Python、项目元数据和 Windows version resource，避免中途不断重出候选。
2. **Agent 首选稳定 JSON CLI。** 任意本地 Agent 都能调用命令行并解析 JSON，先
   把命令和错误语义稳定下来；MCP 只允许作为该接口的薄适配器，不另造业务层。
3. **应用进程是唯一写入者。** Agent 不直接打开 `tasks.db`，不直接编辑 settings，
   不绕过角色生命周期。应用未运行时，写命令返回明确错误，不偷偷启动第二套存储。
4. **完成父任务默认完成整个子树。** UI 在存在未完成后代时显示数量并让用户确认；
   “完成整个子树”为主操作，同时保留“仅完成此项”供特殊情况使用。CLI 必须显式
   提供 `scope=self|subtree`，不可依靠隐藏默认值。
5. **物理删除恢复到 UI。** 归档仍是日常主操作；删除明确显示子树数量并只确认一次。
   Service 的事务边界继续复用，失败不得局部删除或谎报成功。
6. **Markdown 是轻量预览。** 保存原始 Markdown，提供编辑/预览切换；支持标题、
   加粗斜体、列表、任务列表、引用和代码块。不承诺公式、Mermaid、WYSIWYG、任意
   HTML 或远程图片加载。
7. **媒体联动走 Windows 系统媒体会话。** 网易云音乐只是首个兼容目标；不登录账号、
   不抓接口、不读歌单数据库、不模拟网易云内部控件。播放器未公开系统媒体会话时
   如实显示不可用。
8. **不做键盘记录。** 复用 `GetLastInputInfo` 等聚合活动事实，不保存键值、输入文本、
   窗口标题或应用使用历史。所谓“键盘敲击联动”只表示近期有用户输入。
9. **第三方 IP 本地隔离。** 罗小黑可修本地包和本地构建脚本，但所有公开导出和
   官方产物必须机械排除并设反例测试。

## 5. V13-01：版本化本地 Agent 控制协议

在现有 `QLocalServer/QLocalSocket` 单实例设施上扩展或建立独立的本地控制端点。
保留已有 ASCII `show/quiet/panel/panel-close` 命令兼容行为；Agent 请求使用有明确
边界的 UTF-8 JSON 行协议。协议至少包含：

```json
{"protocol":"retirement-pet.agent.v1","request_id":"...","operation":"status.get","args":{}}
```

响应至少包含 `protocol`、原样 `request_id`、`ok`、稳定 `code`、可读 `message`、
`data` 和当前数据 `generation`。失败也必须返回结构化响应与非零 CLI exit code。

要求：

- 单请求和响应有字节上限、读取超时、UTF-8/JSON/schema 校验；一条坏请求不拖死 UI。
- 只接受同机本地端点，服务名绑定当前用户范围；文档说明这不是远程认证 API。
- operation 使用显式 allowlist；不得提供任意 SQL、文件读取、Python、shell、动态
  import 或任意对象属性访问。
- 所有 handler 回到应用线程并调用正式 service/controller；不可从 socket 回调并发
  修改 Qt 控件或 SQLite。
- 日志只记 operation、结果码和去标识 request id；任务标题、备注、媒体标题、路径
  不进入普通日志和 acceptance。
- mutation 支持幂等键或等效机制；超时重试不能重复创建、重复完成或重复删除。
- 每个写操作接受可选 `expected_generation`，陈旧 Agent 得到 conflict，不覆盖用户
  刚在 UI 做的更改。

**验收：** 覆盖半包、超长包、错误编码、错误版本、未知 operation、重复 request、
重连、应用退出、UI 同时编辑和超时重试。用真实 `QLocalSocket` 做至少一组进程间
往返，不只直接调用 handler。

## 6. V13-02：Agent CLI MVP

提供统一入口，建议形式为 `RetirementPet.exe agent <domain> <verb> ... --json`；源码
运行入口保持等价。机器输出 stdout 只写一个 JSON 对象，诊断写 stderr，exit code
稳定。`--help` 给人读，`--json` 给 Agent 读。

MVP 命令：

- `status get`：应用状态、当前动作及来源、当前角色 Revision、面板/勿扰/声音状态、
  Todo 是否可用和 generation；不默认返回任务正文或个人路径。
- `todo list|get|add|rename|note-set|complete|restore|archive|delete|focus-start|focus-stop`。
  list 支持 parent/status/horizon/quadrant/archived/limit/cursor 筛选，返回稳定 task id。
- `action list|status|trigger|stop`：遵守禁用、勿扰、素材回退和优先级纪律；返回实际
  执行动作及拒绝原因，不把“请求已接收”写成“动作已显示”。
- `character list|current|switch`：列出可用 Revision 并走正式安全切换。1.3.0 不要求
  Agent 自动导入、卸载或确认第三方包，这些继续由 UI 承担。
- `media status|play-pause|next|previous`：只在 V13-05 能力可用时执行，返回 session
  身份的低敏摘要和真实结果。

删除命令必须带精确 task id 和 `--confirm-subtree-count N`；数量不一致则拒绝。
complete 必须显式传 `--scope self|subtree`。note-set 从 stdin 或明确文件参数读取，
不得把长备注塞进进程列表；响应不回显完整备注，除非调用者明确执行 `todo get`。

**验收：** 用独立数据目录启动真实应用，从 CLI 完成“查状态 → 建父子任务 → 写
Markdown → 聚焦 → 完成子树 → 恢复 → 归档 → 删除”的端到端流程，同时验证 UI
立即刷新。另测应用未运行、只读/损坏存储、陈旧 generation、重复幂等键、非法 id、
动作被禁用和角色切换失败。CLI 帮助、JSON schema 和退出码写入用户文档。

## 7. V13-03：Todo 删除与任务树完成语义

复用现有 `delete_subtree`，在 Todo 页恢复“删除”入口。删除前计算并展示任务总数、
未完成数和是否包含当前焦点；用户确认后一个事务删除。删除失败保留整棵树和焦点
事实；成功后清理相关草稿、选择和焦点，不触碰其他任务树。归档入口和恢复能力保留。

新增显式完成范围：

- `complete(task_id, scope=self)` 保留旧行为，供兼容调用和特殊场景使用。
- `complete(task_id, scope=subtree)` 在一个事务内完成根和全部未完成后代，保留原
  层级与顺序，并清理位于该子树中的焦点。
- UI 对叶子直接完成；对有未完成后代的节点弹出一次简洁选择，主按钮“完成整个
  任务树（N 项）”，次按钮“仅完成此项”。
- 恢复保持显式范围；默认只恢复所选项，用户可选择恢复整个子树。不能因恢复父项
  自动猜测哪些后代原本由级联完成。

为避免无法还原来源，本版不承诺“恢复父项时只恢复当初被级联完成的那些后代”。
如执行者认为需要该能力，应提出 schema/事件记录方案，由主控决定是否升级 Todo
schema；不得靠时间戳猜测。

**验收：** 混合完成状态、多层树、当前焦点、归档后代、写失败和并发 generation
冲突；UI、CLI、数据库重启后三者一致。迁移已有 v2 数据不改变任何任务状态。

## 8. V13-04：Markdown 备注与优先级可见性

备注侧页增加“编辑/预览”切换，编辑继续使用现有 `QPlainTextEdit` 和草稿保护，预览
使用 Qt 原生 Markdown 能力。数据库仍保存用户输入的原始文本，不做格式化回写，
不需要 schema v3。切换任务、关闭面板、保存失败、恢复备份时继续遵守现有草稿容量
和恢复语义。

安全边界：禁用或转义原始 HTML；不自动加载 `http/https/file/data` 图片及其他远程
资源；点击链接只在用户明确动作后交给受控打开流程。任务列表复选框仅作显示，不能
在预览中暗改 Todo。公式语法原样显示或作为代码处理，1.3.0 不接 MathJax。

主树中每项无需打开详情即可看到重要和紧急状态。默认采用现有“状态”列内的紧凑
标签，并保证标签有文字而非只靠颜色；执行者可在 720×480 实测后改成两个窄列，
但不得引入横向裁切。四象限筛选、键盘导航和屏幕阅读文本保持一致。

**验收：** 中英文、Emoji、长段落、标题、粗体、列表、任务列表、引用、代码块、
恶意 HTML、远程图片和超长无断词文本；720×480 下编辑、预览、保存、优先级识别和
按钮命中均可达。预览不联网、不写源文本、不增加后台轮询。

## 9. V13-05：Windows 媒体会话与网易云音乐兼容

建立独立 `SystemMediaBridge`，优先使用 Windows Global/System Media Transport
Controls 的公开系统会话能力。它与现有 `AudioManager` 分开：前者观察/控制其他
播放器，后者继续播放用户选择的本地文件。UI 清楚显示当前控制的是“本地播放”还是
“系统媒体”。

能力包括：枚举当前系统媒体会话、选择当前活跃会话、读取播放/暂停状态与经过截断
的标题/艺术家、play/pause/next/previous，并把真实播放状态投影为 `core.music`
上下文。网易云音乐桌面版作为首个实测目标，同时至少用另一个公开系统媒体会话或
合成 provider 验证实现不是按进程名硬编码。

要求：

- 默认关闭外部媒体联动，用户在设置中显式开启；关闭后释放订阅和系统对象。
- 优先事件订阅，必要轮询有低频上限，桌宠隐藏/睡眠时暂停；不可破坏 V12 降载成果。
- 不读取账号、Cookie、播放历史、歌单文件、歌词缓存或网易云私有 API。
- 应用可见文案只展示当前会话必要信息；普通日志和验收证据不记录歌曲标题。
- 多会话、会话消失、命令不支持、播放器拒绝、锁屏/睡眠、服务不可用都诚实降级。
- 不用全局媒体键假装已控制指定会话；若实现媒体键后备，必须显式标为无目标广播，
  默认关闭，并单独取得用户同意。

**验收：** provider 合约测试覆盖全部状态转换；Windows 原生集成测试验证系统会话
出现/消失和至少 play/pause。网易云若暴露会话，实测听歌、暂停和切歌；若当前版本
不暴露，报告精确版本与“不可用”结果，不抓内部接口绕过。测量静置、播放和隐藏三
场景 CPU/内存，不能明显破坏已有预算。

## 10. V13-06：工作活动联动

现有 `ActivityMonitor` 与 `RhythmController` 已通过系统空闲时间把持续键盘/鼠标活动
映射为 work，把长时间无输入映射为 rest。本项不重写它，而是补足可解释性、设置和
Agent 状态输出：显示“近期有输入/空闲/未知”及动作来源，允许用户单独关闭活动联动，
并在焦点 Todo 存在时形成清楚的“正在处理该任务”状态，不把任务标题发到气泡或日志。

不得安装低级键盘钩子，不统计具体按键，不区分用户输入了什么，也不记录前台窗口。
如果仅靠 idle time 无法满足更细的“敲击一下触发动画”，宁可保持聚合语义，不扩大
隐私采集范围。

**验收：** 活动、空闲、恢复、未知 provider、勿扰、手动动作优先级、联动关闭、
焦点任务切换和 Agent `status` 一致；睡眠恢复不补算历史活动，关闭后没有计时器或
订阅泄漏。

## 11. V13-07：角色动画和素材质量

### 11.1 原创/可发布角色

为一个权利清楚的原创猫 Revision 提供真实 sequence idle：2–4 秒无缝循环、8–16
个有意义的 512×512 RGBA 帧，并至少提供独立 work/rest 姿态。可以使用 Blender
离线渲染、图像生成加人工修整或其他可复现流程；Runtime 仍只接收 PetPack 允许的
离线资源，不引入 Blender 或实时 3D 依赖。

逐帧保持角色身份、相机、脚底锚、motion bounds 和透明四角稳定。作者源文件放在
PetPack 构建目录之外，包用新 Revision，不覆盖 0.1.1。补齐来源、生成过程、许可、
AI/第三方资产记录，并通过 lint、contact sheet、两次确定性 build、validate、
preflight、preview 和真实 App 播放。

### 11.2 罗小黑本地导入角色

修复仍可复现的背景残留、默认动作头顶裁切和动作间画布不一致。先判断是源 PNG
alpha、geometry/content_bounds、motion_bounds 还是锚点声明错误，再做最小修复；
不得用扩大窗口或忽略 geometry 掩盖。生成视觉接触图并在真实桌面检查。

该包、原图、衍生图、截图和构建产物继续只留内部/本地通道。公开快照与官方候选
加入路径和内容双重反例，证明它们不在产物中。

**验收：** sequence 真实跨帧并在接缝回到首帧；静态动作不多余重绘；角色顶部、
左右和脚底均在可见区，点击区与可见身体一致；缓存预算和性能门通过。内容完成以
产物和视觉证据为准，不以 Todo 勾选或仅有单张 PNG 为准。

## 16. 测试与证据原则

- 测试用户数据全部使用隔离目录和合成内容，不读写日用 `%APPDATA%` 数据库。
- 为新协议、Todo 事务、媒体 provider 和公开导出写有意义的反例；不为简单 getter
  堆数量，也不把 monkeypatch 内部返回值当成端到端证据。
- UI 验收包括真实控件命中、可见区域、关闭/重建和信号释放；不能只断言 label 文本。
- 系统集成分三层报告：纯函数/合成 provider、真实源码应用、真实打包 EXE。层级
  不得混写。
- 性能比较固定场景、时长、采样器和 artifact；报告原始样本及聚合方法。新增媒体
  订阅和 Agent 服务在无客户端时应接近零额外工作。
- 原始证据追加保存，报告可纠错但不能覆盖历史 receipt 或冒充旧候选已经包含新修复。

## 17. 明确不纳入 1.3.0

- 网易云账号登录、私有 API、云歌单/歌词抓取或 Web 自动化；
- 远程网络 API、云同步、多人协作和开放互联网控制；
- 任意 Agent 直接 SQL/文件/shell 权限；
- Markdown 公式渲染、Mermaid、WYSIWYG、附件和远程图片；
- 实时 Blender/Unity/Unreal Runtime；
- 把罗小黑等第三方 IP 作为官方或公开内容发布；
- 在 Agent 命令稳定前另建一套拥有独立业务语义的 MCP 服务。

执行者发现这些能力确有必要时，记录为后续 1.3.x/1.4 候选，不扩张本版范围。
