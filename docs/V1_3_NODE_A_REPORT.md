## 关键取舍

1. **完成语义放在 service 显式 scope，而非改默认。**
   `complete(task_id)` 默认 `scope="self"` 完全保留冻结规则；UI 与
   Agent 都必须显式传 `scope=subtree`，CLI 不允许隐藏默认值。
2. **归档后代在 subtree 完成范围内**（连归档的未完成后代一并完成，
   确认框显示归档数）——与“删除/归档作用于整个子树”的既有规则一致。
3. **恢复不猜来源。** `scope=subtree` 只恢复当前 DONE 的后代，不记录
   也不猜测哪些是当初被级联完成的（工单明确本版不做）。
4. **协议复用单实例服务器**（同一按用户命名管道），首字节 `{` 分流；
   旧 ASCII 命令字节行为不变。
5. **`status.get` 无副作用**：不强制初始化 Todo 存储；generation 只在
   真正打开过存储后有意义。应用线程内同步调用正式 service。
6. 幂等缓存 64 条 FIFO；`expected_generation` 匹配才执行，UI 编辑后
   陈旧 Agent 得 `CONFLICT`。
