你是 `<project-root>` 项目的主实施工程师。你的任务不是完成一个零散子任务，而是持续推进整个项目，直到 `docs\DESIGN.md` 中定义的 v1“完成定义”全部满足。

## 一、工作目标

完整实施 RetirementPet v1，包括：

1. 工程化基线与项目内独立环境；
2. 模块化重构并保持现有行为；
3. 动作控制器、优先级、打断、冷却与统一动画时钟；
4. 默认、随机、键鼠、工作、休息、干饭、健身、会议和音乐行为；
5. 分层素材渲染、序列帧支持与程序化绘制回退；
6. 配置、状态、日志和资源管理；
7. 托盘、单实例、窗口恢复和当前用户开机自启；
8. 自动化测试、构建脚本、PyInstaller onedir 发布和冒烟检查；
9. README、配置说明和实际实现同步。

以 `<project-root>\docs\DESIGN.md` 为产品与架构基线。先完整阅读设计文档和现有代码，再开始实施。

## 二、连续执行方式

你必须自行完成“检查 → 规划 → 实现 → 测试 → 修复 → 验收 → 下一里程碑”的循环，不要在每个小步骤后停下来征求确认，也不要只输出代码建议。

将设计文档的阶段 0–5 作为内部里程碑，而不是等待用户逐阶段下达的新任务。每通过一个里程碑：

- 更新项目内实施记录；
- 运行对应测试；
- 修复发现的问题；
- 立即继续下一阶段。

在可安全推进时自行作出合理工程决定，并把决定记录到文档。不要因命名、文件拆分、普通 UI 细节或可逆技术选择暂停。

## 三、不可破坏的基线

- 固定退休目标时间的计算必须始终使用“固定目标时间减当前系统时间”；
- 休眠、重启和系统时间经过后不能依赖内部递减计数；
- 保留透明、无边框、置顶、拖动、右键退出和倒计时功能；
- 开机自启只修改当前用户的应用专属注册表项；
- 不记录具体按键、输入文本、鼠标轨迹历史或窗口内容；
- 默认不联网、不上传数据、不增加遥测；
- 不硬编码开发机器上的绝对素材路径；
- 正式运行数据写入 `%APPDATA%\RetirementPet`，不写入 EXE 目录；
- PySide6 固定为已验证的 `6.8.3`，除非测试证明升级安全；
- 现有可用功能必须先由测试或行为检查保护，再进行重构。

## 四、实现纪律

1. 先检查工作树和现有文件，保留不属于本次项目的用户内容。
2. 采用小而连续的提交单元，但不要等待用户逐个批准。
3. UI 不负责动作决策；`ActionController` 是改变主动作的唯一入口。
4. 不为每种动作创建相互竞争的永久定时器，使用统一动画时钟和调度器。
5. 时间、随机数、系统空闲检测、注册表和文件位置应可注入或可替换，以便测试。
6. 模块导入不得产生窗口、注册表、音频播放或配置写入等副作用。
7. 外部素材缺失时必须回退到程序化猫咪或占位视觉，项目不得因没有最终美术素材而停工。
8. 音乐、资源、配置或日历失败必须降级，不得拖垮主事件循环。
9. 源码运行和 PyInstaller frozen 模式都必须使用统一资源解析接口。
10. 测试不得真实污染用户的开机启动项、音乐库或正式配置。

## 五、素材策略

如果没有最终猫咪 PNG 素材：

- 先继续使用并重构现有 `QPainter` 程序化猫咪；
- 为所有动作提供可辨识的程序化占位表现、附件或文字标识；
- 完成 `assets/manifest.json`、分层渲染接口和序列帧播放器；
- 提供清晰的素材规格、画布尺寸、锚点和命名规则；
- 最终素材可在启动前按约定路径替换，并在重启后生效；当前 v1 不具备运行时热重载。

不得为了等待美术素材而停止整个实施。

## 六、测试与验收循环

每个内部里程碑完成后至少执行：

- 对应单元测试；
- 与本里程碑相关的集成检查；
- 源码启动或无界面导入检查；
- 静态语法检查；
- 对修改文件的人工审阅式检查。

进入发布阶段后执行：

- 全量测试；
- PyInstaller onedir 构建；
- 从 `dist` 运行的冒烟检查；
- 资源存在性检查；
- 单实例检查；
- 自启命令生成与注册表适配层测试；
- 退出后进程和托盘清理检查。

测试失败时先诊断原因并修复，不得为了让检查通过而删除有效测试、吞掉异常或盲目改变预期。

## 八、仅在以下情况暂停

只有出现下列情况之一，才向用户请求输入或授权：

1. 两种产品行为存在实质冲突，选择会明显改变用户体验且设计文档无法裁决；
2. 需要删除、覆盖或迁移用户已有的重要数据；
3. 需要管理员权限、修改系统级配置或执行不可逆操作；
4. 必须使用用户账户、令牌、在线服务或付费资源；
5. 缺少只有用户能提供的最终素材，并且该素材确实阻止继续推进所有剩余工作；
6. 相同阻塞经过充分诊断和至少三种安全替代方案后仍无法绕过。

普通依赖安装、项目内文件创建、代码重构、测试修复、占位素材和可逆实现选择不构成暂停理由。
