## 2026-09-01

### 半写实猫 0.1.1 公开净化 Revision

0.1.0 的角色 PNG 含一个公开媒体 allowlist 之外的 `caBX` ancillary chunk。没有
覆盖这份旧事实：内部仓库继续冻结原 0.1.0 canonical，公开快照只按完整相对路径
排除该旧包。新 0.1.1 使用仓库内确定性工具移除该 chunk，不重新编码图片；全部
IDAT 与 QImage RGBA8888 解码结果逐字节一致。应用 pin、smoke gate、测试、资产清单
和作者记录同步指向新 Revision。

### 公开源码基线

本轮为公开仓库建立 MIT 代码与文档许可、贡献指南、安全报告入口、PR/Issue 模板、
只读权限的 Windows CI 和机器中立公开快照。`main` 的远端规则要求 PR、测试和维护者
审核；角色内容必须说明作者、来源、许可、AI 使用和公开再分发权。

公开快照从当前干净 HEAD 读取 Git blobs，建立全新的单 root commit，不继承私有
开发历史。它只保留脱敏的 `evidence/README.md`，排除其余 raw evidence、`.release`、
虚拟环境、构建目录和本地数据库，并拒绝个人路径、机器标识、高置信密钥和不安全
归档。私有原始事实继续追加保存，不因公开导出而覆盖或删除。

现有 1.1.1 onedir 没有携带完整第三方许可与 NOTICE，不能作为公开二进制上传。
首次公开基线因此是源码预览；便携版须从公开提交重建，并把实际组件清单、许可文本、
LGPL 对应源码入口和 artifact 摘要纳入新门禁。
