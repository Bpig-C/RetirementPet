本目录目前没有运行时 PNG，只保留这份说明。它曾用于 v1
`assets/manifest.json` 的分层部件与序列帧约定，不再是 1.1.1 扩展新角色的入口。

当前官方角色和半写实示例都以不可变 `.petpack` 分发，可编辑角色素材放在
[character-work](../../character-work/README.md)。不要把新图片直接丢入此目录并
期待角色库自动发现；应先完成 manifest、权利与来源声明，再构建、验证和导入。
