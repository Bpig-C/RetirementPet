# RetirementPet 资产许可映射

> 返回[文档中心](../docs/README.md)和[项目许可说明](../docs/LICENSING.md)。
> 当前角色公开边界见[角色资产发布裁定](../docs/CHARACTER_ASSET_RELEASE_DECISION.md)。

本目录采用逐项许可，不以文件位置推断授权。

| 路径 | 许可 | 说明 |
|---|---|---|
| `icons/retirement_pet.png` | [MIT](../LICENSE) | RetirementPet 原创应用图标 |
| `icons/retirement_pet.ico` | [MIT](../LICENSE) | 上述原创图标的 Windows ICO 导出 |
| `manifest.json` | [MIT](../LICENSE) | 旧版原创资产配置数据 |
| `sounds/README.md`、`sprites/README.md` | [MIT](../LICENSE) | 项目文档；目录当前不含可分发媒体 |
| `petpack/*.petpack` | 包内独立许可 | 每个归档以 `legal_file_ref` 指向的文本为准，不适用根 MIT |
| `petpack/examples/*.petpack` | 包内独立许可 | 半写实预览保持现有项目范围授权，不适用根 MIT |
| `petpack/README.md` | [MIT](../LICENSE) | 项目文档，不改变归档内容许可 |

当前裁定允许官方退休猫与半写实退休猫 0.1.1 原样随 RetirementPet 公开快照和
官方二进制分发；这不把其媒体改为 MIT 或开放内容。半写实 0.1.0 继续从公开快照
排除。罗小黑及其他无可核查授权的第三方 IP 不得进入本目录或官方发行物。

未来新增图片、声音、字体、模型或角色包时，必须在本表或对应包内 `legal/` 文件中
明确作者、来源、许可、署名和再分发范围。没有映射的媒体资产不能进入官方 Release。
